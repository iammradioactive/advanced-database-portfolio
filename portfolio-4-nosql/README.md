# Portfolio 4: NoSQL and Advanced Data Models

## Case study
Lagoon Market. Use the same organisation and keep identifiers and data
consistent with the relational implementation wherever they are shared.

## Required evidence
The assessment requires a NoSQL model based on the same case study,
a document/key-value/column/graph example, implementation evidence and
an explanation of suitability (MIVA Open University, 2026, p. 3).

## Where to put the work
Keep this activity's files inside this folder. Suggested organisation:

- `scripts/`: executable setup, data insertion and query scripts.
- `data/`: simulated sample records and their provenance.
- `results/`: actual operation outputs and verification results.
- `screenshots/`: genuine captures where useful.
- `model-and-suitability.md`: describe the selected model, keys,
  access patterns, trade-offs and why it suits Lagoon Market.

Create these subfolders when adding their files. State the technology
actually used rather than assuming that a particular product is mandatory.

## Implementation and verification
Add installation prerequisites, exact execution commands, actual version,
observed results and any untested features after implementation.
No NoSQL implementation is included in this structure-only package.
