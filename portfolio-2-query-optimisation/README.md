# Portfolio 2: Query Processing and Optimisation

## Case study
Lagoon Market, the same fictional online retailer used in Portfolio 1.

## Required evidence
The assessment requires SQL queries, query results, execution plans,
indexing/optimisation evidence and a brief performance analysis.

## Where to put the work
Keep this activity's files inside this folder. The following names are
organisational suggestions, not additional university requirements:

- `queries/`: original and optimised SQL queries.
- `results/`: actual query outputs and before/after timing measurements.
- `execution-plans/`: actual plans captured before and after optimisation.
- `performance-analysis.md`: explain the change, measurement method,
  result equivalence, observed improvement or regression, and limitations.
- `screenshots/`: genuine captures where useful.

Create these subfolders when adding the corresponding files; they are not
populated by this structure package.

## Implementation and verification
Replace this section with the actual database version, prerequisite files,
commands executed, test results and any limitations after doing the work.
This README is a structure guide, not evidence that a query was executed.
