# Portfolio 5: Distributed and Cloud Database Exercise

## Case study
Lagoon Market, using the same retail and warehouse scenario as the
other four portfolio activities.

## Required evidence
The assessment permits a distributed/cloud database discussion or setup
based on the same case study, including replication, sharding,
availability, consistency, or deployment evidence
(MIVA Open University, 2026, p. 3).

A paid cloud service or a live cloud deployment is not explicitly required
by that wording. Do not present a proposed architecture as a deployed one.

## Where to put the work
Keep this activity's files inside this folder. Suggested organisation:

- `architecture.md`: explain the selected approach and its trade-offs.
- `diagrams/`: architecture diagram matching the discussion or setup.
- `config/`: configuration and deployment files, where applicable.
- `results/`: actual execution and failure/recovery evidence, where tested.
- `screenshots/`: genuine captures where useful.

Create these subfolders when adding their files. Clearly separate what
was discussed, configured, executed and left untested. For an implemented
setup, record commands, node roles, versions and actual observations.
