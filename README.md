# advanced-database-portfolio

## Selected Organisation: Lagoon Market

Lagoon Market is a fictional online retailer that sells household goods, groceries and electronics. It operates two warehouses, located in Ikeja and Lekki.

This portfolio uses Lagoon Market consistently across all five database activities. All business records used for testing will be simulated rather than real customer data.

## Database Users

The system supports customers placing orders, warehouse staff managing stock, finance staff checking payments, delivery staff updating deliveries and managers reviewing sales.

## Main Data

The database will store customers, delivery addresses, products, product categories, warehouses, stock quantities, orders, order items, payments and delivery records.

## Key Operations

The system will support placing orders, checking stock, reserving products, recording payments, tracking deliveries and producing sales reports.

A key business requirement is to prevent two customers from successfully purchasing the same last available item.
Failed checkout operations must not leave incomplete ordersor incorrect stock quantities.

## Portfolio Activities

1. Database Design and Modelling
2. Query Processing and Optimisation
3. Transactions and Concurrency
4. NoSQL and Advanced Data Models
5. Distributed and Cloud Database Exercise
